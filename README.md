# iDock

Android-приложение для работы с iPhone и iPad, подключёнными кабелем OTG. Рабочее название, его можно заменить.
Kotlin, Jetpack Compose, Material 3. Минимальная версия Android: 8.0.

## Что есть в версии 0.1.0

| Раздел | Состояние |
|---|---|
| Определение iPhone, iPad, iPod touch по USB, запрос доступа | работает |
| UDID, режим устройства (обычный, восстановление, DFU), копирование по нажатию | работает |
| Светлая и чёрная темы, смена с анимацией от точки нажатия | работает |
| Приветственный гид при первом запуске | работает |
| Окно с автором (github.com/nak1ost), только при первом запуске | работает |
| Модель, версия iOS, имя устройства | следующий этап, см. `docs/` |
| Батарея, память | следующий этап, нужно сопряжение с iPhone |
| Файлы, фото, приложения, резервные копии, рингтоны, снимок экрана, журнал, проверка устройства | интерфейс на демо-данных |

Чего в приложении нет и не планируется: прошивка и откат iOS, джейлбрейк, обход блокировки активации.

На настоящем iPhone приложение ещё не проверялось: сборка проверена тестами на JVM (запуск, гид, вкладки, смена темы, все экраны в обеих темах).

## Сборка

Нужны JDK 17 или новее, Android SDK (platform 36, build-tools 36.0.0) и Gradle 8.13 или новее.

```
gradle :app:assembleRelease        # app/build/outputs/apk/release/app-release.apk
gradle :app:testDebugUnitTest      # тесты; снимки экранов в app/build/shots
```

Путь к SDK указывается в `local.properties` (`sdk.dir=...`).

## Подпись

Ключ лежит в `keystore/`. Обновления устанавливаются поверх приложения, только если подписаны тем же ключом, поэтому
папку нужно сохранить и не выкладывать в открытый репозиторий (она уже в `.gitignore`).

## Что где

- `app/src/main/java/dev/idock/app/device` — работа с USB.
- `app/src/main/java/dev/idock/app/ui` — интерфейс: `shell` (навигация), `dashboard`, `onboarding`, `settings`, `screens` (разделы), `theme`, `kit`.
- `docs/protocol-usbmux-lockdown.md` — описание протокола связи с iPhone для следующего этапа.
- `docs/integration-plan.md` — что из функций выполнимо и в каком порядке делать.
